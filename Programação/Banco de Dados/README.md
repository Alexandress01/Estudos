# 🗄️ Banco de Dados

Materiais de estudo relacionados a bancos de dados, com foco em fundamentos,
modelagem e uso prático com SQL.

## Objetivo
Compreender como os dados são armazenados, organizados e manipulados,
criando uma base sólida para aplicações reais.

## Conteúdos estudados
- Conceitos básicos de banco de dados
- Modelagem de dados
- Tabelas, chaves e relacionamentos
- SQL (Structured Query Language)
- Boas práticas de organização

Esta pasta reúne anotações e scripts usados durante o aprendizado.
