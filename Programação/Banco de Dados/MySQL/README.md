# 🐬 MySQL

Estudos práticos de MySQL focados em aprender SQL na prática,
criando bancos, tabelas e consultas.

## Conteúdos
- Criação de banco de dados
- Criação e alteração de tabelas
- Tipos de dados
- Chaves primárias e estrangeiras
- Inserção, atualização e exclusão de dados
- Consultas com SELECT
- Filtros, ordenação e agrupamentos

## Organização
- Cada arquivo '.sql' representa uma aula ou exercício
- Os scripts contêm comentários explicando o que foi aprendido
- O foco é entendimento e prática, não apenas execução

## Observação
Os scripts foram criados durante o estudo, acompanhando aulas e exercícios,
principalmente de cursos introdutórios.
