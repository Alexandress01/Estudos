## 💻 Programação

Materiais de estudo relacionados a desenvolvimento de software.
Aqui concentro aulas, exercícios e pequenos projetos práticos, 
com foco em aprender fazendo.

## Estrutura
Cada linguagem possui:
- **Aulas** → anotações e códigos acompanhando cursos
- **Exercícios** → prática de lógica e fixação
- **Projetos** → aplicações simples para consolidar o aprendizado

## Objetivo
Construir base sólida em programação e evoluir para o desenvolvimento profissional.
